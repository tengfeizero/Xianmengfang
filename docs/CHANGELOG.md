## v2.3 (2026-11-07) — 后台经营明细：积分 / 点赞 / 使用

- `GET /admin/point-logs`：积分流水明细，`user_id`/`reason`/`keyword`(昵称) 筛选，返回 `summary:{in,out}`（按筛选口径聚合的收入/支出）

**后台前端（3 个新页面 + 下钻入口）**
- 「客户」组新增**积分明细**（汇总条：笔数/累计获得/累计消耗；变动 +绿 −红）；「内容」组新增**点赞明细**（点赞总数/涉及作品/参与用户）与**使用明细**（记录数/累计件数/涉及作品）
